# bapesolucoes

Landing Page responsive criada para a empresa Bape Soluções.

## Visão Geral

Este projeto é uma landing page moderna e responsiva, desenvolvida em HTML e CSS puros. Ele apresenta seções de início, serviços, portfólio, sobre nós, orçamento e contato.

## Arquivos

- `index.html` - Estrutura principal da página.
- `style.css` - Estilos e responsividade para desktop, tablet e celular.

## Como usar

1. Abra o arquivo `index.html` em um navegador.
2. Ou use um servidor local para testar, por exemplo com extensões como Live Server no VS Code.

## Recursos

- Navegação fixa no topo com menu compacto e hamburger
- Layout responsivo para diferentes larguras de tela
- Seção de solicitação de orçamento com envio por email
- Portfólio e apresentação de serviços
- Estilo visual escuro e moderno

## Observações

- O formulário de orçamento envia os dados via AJAX para `formsubmit.co` e exibe confirmação sem sair do site.
- O projeto não depende de frameworks externos.
- Para personalizar, edite `index.html` e `style.css`.
